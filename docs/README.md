# Zapadictos — Documentación del proyecto

Tienda online de zapatillas. Proyecto final de universidad construido con Nuxt, NestJS y PostgreSQL, con la seguridad pensada desde el diseño.

Esta carpeta es la **fuente de verdad** del proyecto. Reemplaza y amplía la "Guía del proyecto" (PDF del 2026-11-03) con las decisiones tomadas en la Fase 0.
